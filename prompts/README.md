# Prompt Library

Proven prompts for building Airrow with Claude Code that the spec-workflow slash commands
(`/createspec`, `/clarify`, `/implement`, `/analyze`, `/push`, `/pr-check`) don't already cover.
Working tools, not documentation — refine them as usage teaches us (they also seed the prompt library
Airrow generates for customers).

- `PROMPT_LIBRARY.md` — the audit/decision prompts.

Conventions: prompts reference repo files rather than restating them; every prompt ends with the expected output form; placeholders in `<angle brackets>`.
