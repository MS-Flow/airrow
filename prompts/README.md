# Prompt Library

Proven prompts for building Airrow with Claude Code. These are working tools, not documentation — refine them as usage teaches us, and fold improvements back in at every milestone self-review (they also seed the prompt library Airrow generates for customers).

- `PROMPT_LIBRARY.md` — the prompts, organized by workflow stage.

Conventions: prompts reference repo files rather than restating them; every prompt ends with the expected output form; placeholders in `<angle brackets>`.
